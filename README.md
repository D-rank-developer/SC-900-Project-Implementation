# SC-900 Core Job Responsibilities: My 5-Stage Workflow Project

This project maps the core domains of the SC-900 exam into five practical, end-to-end workflows that mirror the daily responsibilities of a Security, Compliance, and Identity Fundamentals professional. I will complete these workflows using free and trial environments (Microsoft Learn, Azure Free Account, and Microsoft 365 E5/Entra trial), ensuring I strictly manage budgets, utilize temporary resource groups, and cancel subscriptions before any billing occurs to maintain a £0 cost.

### My Project Workflows

| Project Domain | Core Objective | Key Actions I Will Perform | Final Deliverable |
| --- | --- | --- | --- |
| **1. Identity & Access Management** | Enforce least privilege and MFA to prevent unauthorized access via compromised accounts. | Compare admin roles, manage test/guest users, test Conditional Access vs. Security Defaults, configure SSPR, enable PIM, and review risk reports. | Identity Security Assessment & GitHub README |
| **2. Cloud Network Hardening** | Secure network perimeters and isolate workloads from external exposure. | Build VNets/subnets, configure NSGs/ASGs, secure a VM via Azure Bastion, provision a Key Vault, and benchmark security using Defender for Cloud. | Cloud Network Hardening Report |
| **3. Threat Detection & Response** | Detect and respond to active threats using SIEM and SOAR capabilities. | Deploy Log Analytics and Sentinel, write KQL queries, build a Logic Apps automation playbook, and investigate simulated failed sign-in alerts. | Mini SOC Runbook |
| **4. Data Protection & DLP** | Prevent the accidental or intentional exfiltration of sensitive data. | Create sensitivity labels/policies, apply them to mock data, monitor via Purview explorers, and configure/tune DLP policies in audit and enforce modes. | DLP and Information Protection Playbook |
| **5. Governance, Risk & Compliance** | Ensure audit readiness, manage data retention, and monitor internal risks. | Review Compliance Manager, configure retention policies, run Insider Risk analytics, and execute Purview eDiscovery and audit searches. | GRC & Data Governance Readiness Report |

By executing these phases sequentially, I will build out a comprehensive portfolio that covers approximately 90% of the exam's weighted domains through practical, hands-on implementation.
